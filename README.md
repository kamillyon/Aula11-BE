## Aula11-BE
# 📌 Visão Geral e Funcionamento
O projeto tem como objetivo organizar e disponibilizar informações sobre filmes em exibição, como título, diretor, duração, classificação indicativa, horário de exibição e valor do ingresso. A aplicação conecta a API ao Supabase via cliente oficial da biblioteca @supabase/supabase-js, realizando consultas assíncronas à tabela sessoes_cinema.
# 🛠️ Tecnologias Utilizadas
* Node.js: Ambiente de execução do código JavaScript no servidor.
* Express: Framework web para criação de rotas HTTP e gerenciamento de requisições.
* Supabase (@supabase/supabase-js): Cliente de conexão com o banco de dados PostgreSQL.
* Dotenv: Gerenciamento de variáveis de ambiente sensíveis.
